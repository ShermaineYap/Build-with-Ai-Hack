# Recording the demo video

Devpost needs a public YouTube or Vimeo video, 1–3 minutes (judges may stop at 3:00). Aim for about 90 seconds. Reviewers won't run the code, so the video has to show it working.

## Set up (2 minutes)

1. `npm install` then `npm run build && npm start` (production mode is faster and smoother than `npm run dev`).
2. Open <http://localhost:3000> in a clean browser window at about 1440 × 900. Close other tabs, hide bookmarks, turn off notifications.
3. Zoom the browser to 110% so text is readable on YouTube.
4. Record the screen and your microphone (macOS: Shift-⌘-5 → Record Selected Portion, Options → your mic). No music.

## Shot list

| Time | Show on screen | Say (in your own words) |
| --- | --- | --- |
| 0:00–0:15 | The empty page | Who you are, and the problem: first offer letters are written for HR, and most grads sign without understanding them. |
| 0:15–0:25 | Hover the tagline | What Baca Dulu is, and what *baca dulu* means. |
| 0:25–0:40 | Click **Try a sample letter**, scroll it a little, click **Decode letter** | It's a realistic, fictional letter. Watch the payslip print. |
| 0:40–0:55 | The payslip | RM3,800 gross → RM3,415.94 in the bank. The tax line is about RM10 a month. The probation line: RM3,142 for six months. |
| 0:55–1:15 | Click the red cards one by one: bond, notice, probation | Each one jumps to the exact sentence. RM10,000 bond; 3 months' notice vs 1; 90% pay. Read one "Is this normal?" line. |
| 1:15–1:25 | Scroll to **Ask before you sign**, click **Copy as email**, paste into a blank email | It turns the flags into polite questions for HR. |
| 1:25–1:35 | Back on the app | Built with the Devpost Learn Skill Pack, plan before code; one thing you learned. |

Tips: record 2–3 takes and keep the calmest one. If something goes wrong, keep going and trim it later. The built-in rules don't need the internet, so the demo can't fail on a network call.

## Before uploading

- [ ] No personal windows, emails or notifications visible
- [ ] No API key visible (don't open `.env.local` on camera)
- [ ] Under 3 minutes
- [ ] Uploaded as **Public** (or Unlisted, if the form accepts that) and the link opens in a private window
